# 2026-09-29 永平搜尋麥克風結果修正

## 原因

第三十七屆蘇州盃 CSV 的四筆冠軍／亞軍／季軍記錄，把隊名同時填在「獲獎者」與「所屬學校」欄，並明確標示「隊伍榮譽」。`normalize_honor_type()` 卻只要「所屬學校」欄有值，就優先分類成個人榮譽。結果永平高中「季軍」被加入選手搜尋集合，套上麥克風圖示。

搜尋中的選手列是資訊卡，不是按鈕；麥克風也只是圖示，因此點擊沒有動作。原本卡片沿用可點擊學校按鈕的游標與懸停樣式，容易造成誤解。

## 修正

- 建置程式先尊重明確的個人／隊伍榮譽類型，再用「所屬學校」欄推定未標類型的舊資料。
- 四筆隊伍榮譽恢復為隊伍類別；永平高中不再被當成選手搜尋結果。
- 資訊型選手卡改為一般游標，學校按鈕維持可互動樣式。

## 驗證

- 資料建置無警告；1096 場戰績、310 筆榮譽、38 筆辯題。
- 產生資料中的四筆蘇州盃隊伍獎均標為 `team`；永平高中不再列於 `honorType: player`。
- `git -c core.whitespace=cr-at-eol diff --check` 通過。
