# 賽事循環、簡章隊數與場地時段補值

更新日期：2026-09-29

## 保存與呈現方式

- `data/event-metadata.csv` 的「簡章滿額隊數」保存簡章明載的預計錄取／滿額隊數，生成為 `eventMetadata.brochureTeamLimit`。首頁與賽事頁隊數仍按公開戰績中實際出現的隊名去重計算；簡章名額不會顯示，也不會代替實際隊數。
- 戰績 CSV 可選填「分組名稱」。前端會在賽果左側時段與會場下方，以小型標籤顯示 `↻ 組名`，避免把循環／主題組名塞進較長的賽果備註。
- 推定的數字仍填入一般時段／會場欄，並另存隱藏的「推定依據」及生成欄位 `inferenceNote`；使用者可看到簡潔資訊，資料維護者仍能區分公告明載與推定。
