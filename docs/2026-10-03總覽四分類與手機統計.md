# 2026-10-03 總覽四分類與手機統計

## 目標

讓手機版總覽也能閱讀原先僅桌機呈現的年度統計，並將導覽收斂為「賽事、選手、辯題、統計」四類。

## 修改

- 總覽改成賽事、選手、辯題、統計四個分頁；手機顯示四個短標籤並平均排列。
- 選手分頁整合公開個人獎、逐場出賽紀錄與公布隊伍名單中的選手，支援姓名搜尋並可開啟個人紀錄。
- 統計分頁手機可用，年度卡改為單欄排列，折線圖可左右捲動查看月份。
- 學校與隊伍仍可由全站搜尋、賽事頁連結及單位詳情查詢。
- 更新 `ARCHITECTURE.md`、`README.md`、資源快取版本與本紀錄。

## 驗證

- `node --check app.js`、`node --check js/interactions.js` 與 `git diff --check` 通過。
- Safari 本機實際檢查總覽：賽事清單 41 項、選手清單 550 位、辯題 46 筆；點選選手卡可開啟個人詳情，辯題頁也能呈現清單。
- Safari 本機實際檢查統計分頁：年度選擇、賽事數／參賽隊次／不重複隊伍卡片及逐月圖表均可顯示。
- 已在 CSS 為 640px 以下版面加入四等分短標籤、統計摘要單欄和可橫向閱讀的圖表；未以手機尺寸實機截圖驗證。

## 工作位置

- Mac 本機 `opendebate-mobile-launch`，分支 `main`。
- 依專案發布預設，驗證後提交並推送 `origin/main`。
