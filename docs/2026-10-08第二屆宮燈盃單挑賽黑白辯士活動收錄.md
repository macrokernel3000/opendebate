# 第二屆宮燈盃單挑賽（黑白辯士）活動收錄

## 收錄內容

依更新賽程公告新增三筆單日行事曆活動，避免將不同日期、場地及辯題合併成錯誤的連續賽期：

- 2026-11-01：犇亞商務暨會議中心；「如果有得選，要當痛苦的蘇格拉底／快樂的豬」。第一日賽程維持不變。
- 2026-11-07：犇亞商務暨會議中心；「如果有得選，要當痛苦的蘇格拉底／快樂的豬」。
- 2026-11-08：臺灣當代文化實驗場（C-LAB）共享吧；「若『心之壁』消失，是人類的福音還是喪鐘？」

三筆活動使用同一名稱「第二屆宮燈盃單挑賽（黑白辯士）」，以日期及地點辨識場次。公告提醒選手於比賽開始前十分鐘抵達，遲到者將酌扣保證金；此提醒存於活動詳情。原訊息未提供報名連結、主辦方網址或各日出賽時間，未自行補猜。行事曆可由各日活動卡直接開啟詳情。

## 實作與驗證

- 一般活動仍放在 `data/calendar-activities.js`，不併入盃賽戰績、統計或榮譽資料。
- 允許活動沒有外部公告網址；詳情頁保留活動內容，行事曆的網址回到該活動詳情頁。
- 預覽、資料預檢、前端與 Python 測試完成後推送 `main`；公開部署需待 GitHub Pages 完成後確認。
