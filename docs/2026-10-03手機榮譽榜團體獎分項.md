# 2026-10-03 手機榮譽榜團體獎分項

## 目標

手機榮譽榜開啟團體獎時，清楚顯示冠、亞、季、殿四類，版面沿用獎級徽章，且兼容個人獎同時開啟。

## 修改

- 團體獎由單一「團」合計徽章改為冠、亞、季、殿四項橫列；為節省手機空間，數量為零的獎級不顯示。
- 團體獎徽章與個人「佳／優」及總數保持單列、不換行，壓縮徽章間距並讓隊名欄收縮以容納摘要。
- 更新 `README.md`、`ARCHITECTURE.md` 與資源快取版本。

## 驗證

- `node --check app.js` 與 `git diff --check` 通過。
- Safari 本機首頁已載入，首頁統計、賽事時間軸、賽事清單及桌機榮譽榜均有內容；網站未見載入故障。
- Safari 截圖回饋指出部分隊伍摘要換為兩列；追加 CSS 設定窄版徽章尺寸與不換行橫列。桌機 Safari 未觸發手機斷點，本次未在實際手機裝置或響應式模擬器確認像素級間距。
