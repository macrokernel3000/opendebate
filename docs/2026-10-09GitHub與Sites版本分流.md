# GitHub 公開版與 Sites 會員版分流

- GitHub Pages 版是公開網站，不包含會員制度。
- Sites 版包含會員制度。
- 兩個版本尚未合併，必須視為不同部署目標；修改其中一版不代表另一版同步更新。
- 公開賽事資料可按需求分別同步，但不可因此將 Sites 的會員功能帶進 GitHub 公開版。
- 每次開始網站修改前，先確認使用者指定的是 GitHub 版或 Sites 版；若同一需求要兩邊都有，逐版完成並分別驗證。

## 維護時的提醒

以此文件與 `AGENTS.md` 為後續 AI／Dot 協作的工作依據。除非使用者明確要求整合架構，否則維持兩版分流，不推定需要合併。
