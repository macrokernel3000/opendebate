# 賽事簡稱獨立欄位

## 目標

- 為公開網全部 67 筆盃賽建立獨立的 `shortName` 欄位。
- 完整正式名稱維持不變；簡稱只負責精簡畫面顯示與對外資料輸出，不作為賽事識別碼或網址鍵值。
- 公開網產生資料與 V1 catalog 共用同一個來源，避免兩邊名稱不一致。

## 已確定規則

1. 每個簡稱都先寫西元年份，再加半形空格與穩定核心名稱，例如：`2026 蒙泉盃`、`2026 蘇州盃`、`2026 辯革盃`。
2. 使用者指定值為：`2026 桃青盃`、`2026 氣候盃`、`2026 西灣盃`。
3. 不以程式截字產生簡稱；每筆賽事都必須在資料表內明確填寫。
4. 不同年度可以使用相同簡稱；賽事仍以既有 `competitionCode` 識別。

## 使用者已確認的特殊名稱

1. `2026法可夢學院線上奧瑞岡式辯論賽（高中組）`：`2026 高中法可夢`
2. `2026 全國大專院校法律系辯論公開賽`：`2026 大法盃`
3. `第六屆台北市政願景盃辯論比賽`：`2024 願景盃`
4. 宮燈盃青少年組保留組別，例如 `2026 宮燈盃青少年組`；大宮燈的公開組日後另算。

## 預定修改位置

- `data/competition-registry.csv`：新增並保存 `shortName`。
- `tools/build_data.py`：驗證每場賽事都有簡稱，輸出至網站資料。
- `tools/ios_public_feed.py`：將同一簡稱帶入 V1 catalog；不改動 iOS 程式。
- 賽事詳情頁：正式名稱與「簡稱」分開顯示，不用簡稱取代正式名稱。
- `AGENTS.md`、`ARCHITECTURE.md`：補上維護規則。
