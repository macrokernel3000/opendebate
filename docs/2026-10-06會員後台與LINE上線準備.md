# 會員後台與 LINE 上線準備

## 已完成的私人驗證

私人 Site 已具備會員個人紀錄、資料回報、管理者審核、操作稽核、同源寫入檢查、角色權限及頻率限制。公開資料以快照讀取，回報不會直接修改公開站。

## 公開站這個分支的行為

- 新增 `member.html` 作為將來的會員入口。
- `js/member-config.js` 預設 `enabled: false`，所以主站不顯示會員入口，也不會把私人測試網址提供給訪客。
- 上線時只接受 HTTPS 後台網址；任何 LINE Channel secret 或管理密鑰都不得寫入前端檔案。
- 會員頁目前標示 `noindex,nofollow`，正式開放並連入導覽後再評估是否移除。

## LINE 正式啟用前必要條件

1. 建立 LINE Login Channel，設定正式 callback URL。
2. 由伺服器保存 Channel secret；前端只取得可公開的登入入口。
3. 實測 OAuth `state`、nonce、PKCE、token、登出、撤銷與重播阻擋。
4. 確認同一 LINE `sub` 穩定對應同一會員，不依賴 email。
5. 以兩個測試帳號確認 A 不能讀寫 B 的私人紀錄或回報。
6. 確認 reviewer/owner 角色不可由會員自行修改。
7. 備份正式資料庫後，才把 `enabled` 改為 `true` 並加入主導覽。

## 回復方式

正式登入發生異常時，把 `enabled` 改回 `false` 即可關閉公開入口，不影響公開賽事資料與既有靜態功能。
