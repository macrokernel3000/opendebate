# 總覽學校與隊伍左右分區

- 使用者指出「總覽－隊伍」應分為學校與隊伍，桌面也要呈現。
- 現況核對：2026-10-04 的桌面與手機都使用同一張混合學校／隊伍清單，手機 CSS 只將卡片改為單欄，沒有保留分類。
- 歷史參照：[`手機版正式上線整合.md`](手機版正式上線整合.md) 的 2026-09-29「總覽隊伍清單調整」記錄，當時將學校與組隊左右分區，以淺綠、淺黃區分，依參賽場數、勝場、榮譽、參賽賽事或名稱排序，並提供排序方向；窄螢幕仍維持左右雙欄。
- 修改：恢復學校與隊伍左右分區、色彩提示、共用搜尋及排序控制；桌面與手機使用同一資訊架構，手機維持緊湊雙欄。
- 資料分型：名冊 `type=s` 歸入學校，其餘已登錄參賽單位歸入隊伍；兩區數量依目前搜尋結果即時更新。
- 驗證：桌面與 390px 手機預覽都呈現學校左／隊伍右的雙欄及不同底色；名冊計數為 160 所學校、137 支隊伍。以「白烏鴉」搜尋確認學校區顯示 0 項、隊伍區顯示白烏鴉辯論隊，兩區共用篩選有效；`git diff --check` 通過。
