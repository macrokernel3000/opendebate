# 手機版正式上線整合

## 目標

把已審查的手機介面帶入 GitHub 公開版，同時保留公開版的資料與桌面呈現。

## 實作

- 以 `origin/main` 為底，保留現有公開資料、favicon、SEO 與桌面版基準。
- 整合手機底部五格導覽、首頁近期賽果與未來賽事、總覽時間軸及手機賽事詳情。
- 手機近期賽果只列冠軍、亞軍、季軍及全程最佳；不列單場最佳。手機詳情先顯示榮譽，桌面維持賽果先顯示。
- 未來賽事標題使用「未來賽事」，卡片明示「辯題：」；總覽標題移除 emoji。
- 未修改或重建公開賽事 CSV 及 `data/public-data.js`。公開資料含第二十屆宮燈盃。

## 驗證

- `node --check` 檢查修改的 JavaScript。
- `python3 -m unittest discover -s tests -v`：5 項通過。
- 瀏覽器檢查手機首頁、未來賽事、宮燈盃詳情及總覽；檢查桌面首頁、總覽與賽事詳情版面。
- 操作檢查包括五格導覽、漢堡選單、前往搜尋、賽事名稱搜尋及年份篩選。

## 發布狀態

- 2026-09-28 已發布至 GitHub Pages 使用的 `main`，程式提交為 `9ebed99`。
- 線上網址：<https://macrokernel3000.github.io/opendebate/>。
- 發布後確認正式網址載入 34 場賽事、1096 場賽果，並可見最新收錄的宮燈盃。
- 桌面版在 1280px 檢視維持公開版原本版型；手機版於本機 320px、393px 檢視及操作。
