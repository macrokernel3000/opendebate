# 2026-09-29 榮譽榜與隊伍統計

## 目標

- 首頁榮譽榜縮窄，手機可同時看到兩張排行卡，排行列更精簡。
- 榮譽榜可一鍵切換最近兩個有資料的年度與全年度，兩種狀態採不同顏色。
- 每場賽事依實際參賽隊伍名稱去重計算隊數，賽事摘要以「幾隊、幾場、幾榮譽」呈現。
- 每場賽事另保存年齡限制狀態；未查明時維持未確認，不在網頁顯示。

## 執行方式

- 主要工作位置：Mac mini `/Users/kernel/Documents/Codex指定內容/辯論嘗試/opendebate-mobile-launch`
- 分支：`feat/event-team-count-and-honor-tabs`
- 資料來源：`data/public-data*.csv`、`data/event-metadata.csv`

## 驗證與成果

- `python3 tools/build_data.py` 完成：34 個賽事、1096 場戰績、310 筆榮譽、38 筆辯題，無略過資料或警告。
- 產生資料包含 34 個賽事的 `teamCount`；隊伍數均大於 0。宮燈盃依逐場隊名去重為 17 隊，西灣盃為 16 隊。
- 年齡限制狀態以 `true / false / null` 保存；宮燈盃青少年組已確認為 `true`，其餘未查明的賽事保留 `null`。
- 本機瀏覽器確認兩個榮譽範圍可切換，榮譽榜按最近兩個有資料的年度計算；年齡限制字樣不會出現在網站畫面。
- 本機預覽成功載入首頁與完整賽事摘要；桌面畫面檢視通過，手機卡片寬度與密度依響應式 CSS 設定。
- `git diff --check` 通過。
