# 網頁檢修與回歸清單

每次更動網站時先檢查受影響頁面；涉及共用導覽、資料載入、版面樣式時，再跑跨頁項目。每一項都分開標記「程式檢查」與「實際畫面／操作」，單元測試通過不能代替瀏覽器檢視。

## 全站共用

- [ ] 首次載入、首頁快照替換、資料失敗提示均可理解，頁面沒有空白停住。
- [ ] 桌面與手機導覽都能到五個主頁面；瀏覽器上一頁／下一頁和深連結可用。
- [ ] 主要控制可用鍵盤操作；焦點清楚可見；暫時視窗可用 Escape 關閉並將焦點送回合理位置。
- [ ] 文字縮放至 200% 後，主要內容和表單仍可閱讀及操作。
- [ ] 手機內容無不必要的橫向捲動；固定底部導覽、瀏覽器安全區與軟鍵盤沒有遮住最後操作。
- [ ] 瀏覽器主控台沒有新增錯誤；圖片、資料檔及頁面深連結可載入。

## 頁面與核心流程

### 首頁

- [ ] 快照載入及更新提示；資料狀態列與已收錄賽事數一致。
- [ ] 時間軸、近期賽事卡、未來賽事卡能開啟正確賽事頁。
- [ ] 榮譽榜年度、團體獎／個人獎／其他篩選和名次呈現正確。
- [ ] 頁面最底部行事曆入口、聯絡／回報資訊不被導覽遮擋。

### 總覽

- [ ] 賽事、隊伍、辯題、統計四頁籤均能切換並正確顯示空結果。
- [ ] 隊伍頁學校與隊伍分欄、搜尋、排序、分頁及詳情連結一致。
- [ ] 統計年度、指標切換會更新圖表標題、資料與中央時間軸；窄螢幕月份可讀。

### 搜尋與詳情

- [ ] 搜尋學校、隊伍、選手、辯題；空結果、別名及中文字輸入狀態可理解。
- [ ] 學校／隊伍、選手、辯題、賽事深連結可由直接網址開啟，彼此關聯連結正確。
- [ ] 長名稱、題解、隊伍名單、賽果與榮譽在手機及桌面均可閱讀。

### 建檔與回報

- [ ] 選手與隊伍模式可切換；表單驗證、平均值、修改、刪除及 CSV 匯入／匯出正常。
- [ ] 無資料時圖表放大停用；有資料時圖表正確顯示並可鍵盤操作。
- [ ] 回報表單入口、整理指令複製鈕、Email 與 Threads 連結可辨識且可開啟。
