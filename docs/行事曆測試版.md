# 首頁行事曆測試版

- 首頁最底部只顯示「行事曆｜測試版」按鈕與 iOS／Android 簡短備註，首頁不顯示月曆或賽事清單；移除頁尾戰績積分說明連結。
- iPhone 訂閱入口使用 `webcal://macrokernel3000.github.io/opendebate/calendar.ics`。這是唯讀訂閱；使用者加入一次後，手機依系統更新週期取得後續異動。Android 點按時改開 HTTPS `.ics` 檔，以便下載並交由已安裝的行事曆 App 匯入。
- `calendar.ics` 由 `tools/build_data.py` 根據 `data/upcoming-events.js` 產生，只包含仍未結束的未來賽事；網站月曆另外讀取歷史戰績與已確認賽期。
- 使用者可在 iPhone 行事曆「新增訂閱行事曆」輸入或點擊訂閱連結。Android 上的 Google Calendar 不支援在手機 App 直接新增 URL 訂閱，需先透過網頁版加入，再由帳號同步。
- 驗證：以本機瀏覽器開啟首頁，確認頁尾只有一顆訂閱按鈕，並確認 ICS 輸出含 6 場尚未結束的未來賽事、all-day 日期採結束日不含式。
- 限制：尚未用實體 Android 裝置驗證 `.ics` 匯入流程。Google 行事曆 Android App 不支援直接訂閱網路行事曆；HTTPS `.ics` 匯入是單次匯入，不會自動同步更新。Google 官方要求先在網頁版以網址新增訂閱。訂閱刷新由各日曆服務管理，不能保證網站更新後立即出現在手機。
