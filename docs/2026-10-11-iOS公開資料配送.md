# iOS V1 公開資料配送（2026/10/11）

## 目標與邊界

- 公開網站新增、修正或一般撤下一場賽事後，iOS V1 不需重新上架才能取得新版公開資料。
- 本 repository 仍是唯一人工與生成來源；會員 Sites、D1、帳號、私人紀錄與管理資料不進入配送檔。
- 不新增後台。GitHub Pages 只發布靜態 `data/ios/v1/manifest.json` 與 `catalog.json`。

## 已完成

- `tools/build_data.py` 以同一份通過公開資料檢核的 payload 產生 App 專用完整快照。
- 賽事使用 `competitionRegistry` 的永久 `CYYNN` 代碼；場次沿用既有穩定 match ID。
- manifest 包含格式版、資料內容版本、SHA-256、bytes、產生時間與賽事／場次筆數。
- App 更新檔只保留賽事摘要與場次欄位，不複製約 1 MB 的完整網站資料，也不包含會員資料。
- GitHub 資料檢查與 Google Sheet 更新流程已納入兩個新生成檔；生成差異比較會忽略建置時間，但不忽略內容版本與筆數。

## 本機驗證

- 嚴格資料預檢：59 個有戰績／榮譽／辯題的賽事、1,427 場戰績、508 筆榮譽、50 筆辯題，0 則提醒。
- App 快照：60 個公開賽事（包含只有公開名單的賽事）、1,427 場場次；catalog 約 456 KB。
- Node 前端 77 項通過；Python 50 項通過；iOS 的網路更新與 UI 驗證另記在相鄰 `opendebate-ios-app` 交接。

## 發布驗收

- 本文件建立時仍是本機成果。推送 `main` 後，須確認 GitHub 資料檢查與 Pages 部署成功，再以 HTTPS 讀回 manifest 和 catalog，核對 SHA-256、bytes、內容版本與筆數。
- 只有公開讀回完成，才可稱為 App 已有可用的線上更新來源；App 本身上架狀態仍須獨立驗收。
