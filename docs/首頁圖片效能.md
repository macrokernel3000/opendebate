# 首頁圖片效能改善（2026-09-19）

## 修改

首頁主圖改用 debate-banner.webp，1813×868、WebP quality=85、method=6，來源為既有 PNG。新增 width、height 與 fetchpriority="high"，維持原本 CSS 裁切與替代文字。原始 PNG 保留，og:image 沿用 PNG；一般首頁瀏覽不會因 og:image 而額外下載原圖。

PNG 1,941,349 bytes → WebP 132,892 bytes，減少 93.2%。未更動賽事資料、JavaScript、樣式或加入網站執行相依套件。

## 驗證

Playwright／Chromium，本機 Python 靜態伺服器，停用快取，CDP 模擬下載 200,000 bytes/s（1.6 Mbps）、延遲 80 ms。兩次使用同一份 HTML，只於測試攔截中切換 PNG／WebP，其餘資源相同；每版本一次，供方向性比較，不代表正式站保證。

| 項目 | PNG | WebP |
| --- | --- | --- |
| 圖片 resource duration | 14,552 ms | 2,159 ms |
| 整頁 loadEventEnd | 14,578 ms | 5,519 ms |

本機伺服器未壓縮 JavaScript，與 GitHub Pages 的壓縮及路由不同，不應把上述整頁秒數直接套用到公開站。

- 1440×900 與 390×844 截圖檢視通過；手機無頁面橫向溢出。
- WebP 完整載入，原始寬度 1813；resource timing 確認首頁未下載 PNG。
- 網站統計維持 33 賽事、1073 戰績、281 榮譽；5 項既有 unittest 通過。
- 瀏覽器 console 0 errors／0 warnings。
- 本次未重測建檔 CSV 流程，因未修改任何相關程式；公開站上線後的效能仍待量測。

## 維護與回復

替換主圖時從原始 PNG 重新轉出同名 WebP，避免反覆壓縮 WebP。轉檔可使用 Pillow 的 Image.open(...).save(..., format="WEBP", quality=85, method=6)；Pillow 僅供維護轉檔，訪客不需要安裝。

如需回復，可將首頁 img 的 src 改回保留的 assets/debate-banner.png，或還原本次 Git commit。
