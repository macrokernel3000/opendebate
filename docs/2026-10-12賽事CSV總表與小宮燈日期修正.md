# 賽事 CSV 總表與第十九屆小宮燈日期修正

## 目標

- 將歷史賽事資料收斂為一份可直接用 Numbers、Excel 或試算表編輯的 CSV。
- 沿用根目錄既有更新工具，並在寫入網站生成資料前先做嚴格預檢。
- 將第十九屆宮燈盃青少年組賽期改為 2025-08-02 至 2025-08-03；現有兩場第二天賽果與單場榮譽日期改為 2025-08-03。

## 成果與工作位置

- 唯一正式賽事來源：`data/public-data-所有賽事.csv`
- 舊逐賽事來源封存：`data/賽事分檔封存/`
- macOS 更新入口：`更新網站資料.command`
- Windows 更新入口：`更新網站資料.ps1`

總表採 25 欄固定順序，保留原有欄位，並加入選填的「來源名稱、來源網址、資料ID」。其中「資料ID」保存網站既有場次與榮譽的永久識別，避免合併總表或修正其他欄位後讓收藏／深連結失效。另新增欄位說明與三種資料列範例；來源與推定分開，沒有可靠來源的舊資料保持空白。封存檔只用來追查遷移前資料，不再由網站讀取。

2025「青聲說」舊資料中可明確認定為循環代號的 A 至 G、甲至辛及「高雄青年」各字，已由備註移到「分組名稱」；棄賽、票數等真正備註完整保留。

## 安全界線

更新工具先執行 `tools/build_data.py --check --fail-on-warnings`。任何錯誤或提醒都會停止正式建置，因此不會以有問題的總表覆蓋既有 `public-data.js`。賽事 CSV 不再用拖曳方式匯入，以免總表與單一賽事檔同時存在；單位名冊仍保留原本拖曳更新方式。

## 驗證

- 總表與 59 份封存來源同為 1,985 列；差異限於已記錄的小宮燈日期修正、青聲說分組欄位正規化，以及新增的空白來源欄。
- 嚴格資料預檢：59 個賽事、1,427 場戰績、508 筆榮譽、50 筆辯題，沒有提醒。
- Python 單元測試 60 項通過，包含重複欄名與欄位溢位拒絕；前端 Node 測試 81 項通過。
- 正式重建成功，網站與 iOS 公開資料均顯示賽期 2025-08-02 至 2025-08-03，現有第二天資料顯示 2025-08-03。
- 使用試算表渲染檢查總表與範例檔均為 24 欄、無欄位位移或公式錯誤，並核對小宮燈五列。
- 以 Chromium 本機受控瀏覽器設定 390 × 844 與 320 × 844 檢查青聲說賽事頁；循環／分組標籤與原備註分開顯示，沒有頁面級橫向溢出，來源維護欄未出現在公開畫面。這不是 Safari 引擎或真機驗收。

## iOS 公開搜尋索引（2026/10/12）

- 同一份 `data/ios/v1/catalog.json` 現在原子包含公開索引，不再讓 App 另外下載一份可能與賽事 catalog 不同版的資料。
- 索引涵蓋 311 個學校／隊伍、776 位公開名單人物、1,427 場戰績、508 筆榮譽與 50 筆辯題；人物角色與所屬單位只取自公開名單／榮譽，不推定缺少的身分。
- 既有 1,427 個場次 ID 與 508 個榮譽 ID 和本分支開始點逐一比對，移除 0、增加 0；總表化不會使舊收藏失聯。
- `publicIndex.generatedAt` 必須與 catalog 同版，索引引用的賽事也需存在於同一份 catalog；App 只有在整份 SHA、bytes、schema 與引用檢查通過後才啟用。

## 下一步

之後新增賽事時，先參考 `data/賽事資料欄位說明.md` 與 `data/新增賽事範例.csv`，只在總表新增相同賽名的資料列，存成 UTF-8 CSV，然後雙擊對應作業系統的更新工具。不要編輯封存資料夾內的逐賽事檔。
