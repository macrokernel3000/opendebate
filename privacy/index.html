OPENDEBATE iOS

隱私政策

本政策說明「公開辯論資訊網」第一代 iOS App 如何處理資料。這一代 App 免登入、無會員後台，主要功能是查詢公開辯論賽事、場次與本機收藏。

重點：App 不使用廣告、分析 SDK 或跨 App 追蹤，也不會上傳使用者的搜尋字詞或收藏內容。

App 儲存的資料

  • 收藏的賽事代碼只儲存在這台裝置的 App 資料中。
  • 公開賽事與場次資料包含隨 App 提供的內建版本，以及最近一次成功下載並驗證的公開版本。
  • iOS 備份是否包含 App 資料，由使用者的裝置與 iCloud 備份設定決定。

取消收藏可刪除個別收藏；移除 App 可刪除本機 App 資料。本 App 沒有雲端帳號或會員個人資料可供刪除。

公開資料更新連線

App 會連線到公開 GitHub Pages，檢查並下載公開賽事資料。請求不包含搜尋字詞、收藏內容、聯絡資料或會員資料。

與一般網站連線相同，網路服務供應者可能接收 IP 位址、裝置所送出的連線標頭與請求時間，並依其安全、營運及法律義務處理。公開資料由 GitHub Pages 提供；其處理方式另見 GitHub 隱私權聲明。

資料下載失敗、內容損毀或驗證不通過時，App 會保留內建或最近成功的版本，不會清空可用資料。

外部網站與 Email

只有使用者主動點選公開網站或聯絡連結時，iOS 才會開啟對應的瀏覽器或 Email App。離開本 App 後，外部服務會依各自的隱私政策處理資料；本 App 不會自動送出郵件或表單。
