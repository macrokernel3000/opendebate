# OpenDebate｜公開辯論網

### 尊重隱私，敬畏歷史。
*Respect Privacy. Honor History.*

**讓每一場值得記住的辯論，都有機會被歷史記住。**

OpenDebate 是一項起源於臺灣的公共教育科技計畫，致力於保存競技辯論歷史、整合分散的教育資源，並為辯論社群提供免費、開放且容易使用的數位工具。

我們相信，辯論不只是比賽，更是一種學習思考、理解分歧與公共討論的教育活動。長年以來，許多珍貴的辯論紀錄散落於不同學校、社團、社群平台與歷史文件之中。OpenDebate 希望改變這件事。

## 我們已經做了什麼？

在 Codex 的協助下，一名原本沒有程式開發經驗的教育工作者，開始建立真正服務辯論社群的公共資訊系統。

目前已建立辯論賽事資料庫與公開查詢網站，整合歷年賽事、對戰紀錄、參賽隊伍、辯題、榮譽與學校統計，並持續完善來源追蹤、資料更正與自動化更新機制。

## 下一階段

- **辯論歷史資料庫：** 保存賽事、辯題、對戰紀錄與歷年成果。
- **會員與選手生涯紀錄：** 整理參賽歷程與教育經驗。
- **裁判評分單：** 結構化評分、意見紀錄與 PDF 匯出。
- **辯論計時器：** 支援不同賽制與環節。
- **賽事管理工具：** 協助報名、場次與賽事資訊管理。
- **辯論教育資源：** 分享教材、訓練工具與知識資源。

以上為長期發展方向，不代表全部已在本倉庫實作。

## 我們相信的兩件事

### 尊重隱私｜Respect Privacy

資訊公開不代表個人必須失去隱私。辯論歷史值得保存，參與其中的人也應受到尊重。我們希望清楚區分公共賽事資訊與個人資料，審慎處理蒐集、使用與公開範圍。

**保存歷史，不應以犧牲參與者的隱私為代價。**

### 敬畏歷史｜Honor History

歷史不只是資料的堆積，更是一份對事實的責任。我們重視原始紀錄、資料來源、名稱差異及修正的可追溯性。對無法確認的資訊，寧願留下空白，也不以猜測填補。

**我們不只是希望記住歷史，更希望盡可能正確地記住歷史。**

## 一個小而具體、可以被複製的公共計畫

公共科技的價值不應只由使用者數量、GitHub Stars 或商業估值決定。Codex 讓原本缺乏工程背景、卻理解教育現場需求的人，有機會親自開發工具。

我們希望逐步分享可開放的技術、資料處理經驗與開發方法，讓其他教師、學校及地方社群也能參考、改良與複製。

**讓技術服務理念，而不是讓理念服務某項技術。**

## 開發與維護文件

後續 AI 或新維護者請先閱讀 [ARCHITECTURE.md](ARCHITECTURE.md)，了解載入順序、資料流、SEO 與安全修改規則。Codex 協作規則見 [AGENTS.md](AGENTS.md)。

本倉庫為純公開查詢網站，可直接開啟 `index.html` 使用，不需要額外伺服器。會員與其他進階工具可能由獨立專案開發。

### 資料與更新

- `data/public-data-所有賽事.csv`：歷史賽事主要編輯來源。
- `data/entity-registry.csv`：學校、隊伍代碼及別名。
- `data/event-rosters.csv`：有來源可查的公告名單。
- `data/public-data.js`：自動產生的網站資料，請勿直接修改。
- `tools/build_data.py`：資料建置與驗證程式。
- `templates/賽事登錄模板.md`：新賽事資料整理格式。

新增資料時應保留來源，未知日期或比分請勿猜測。正式資料更新前先執行：

```bash
python -m unittest discover -s tests -v
python tools/build_data.py --check --fail-on-warnings
```

Windows 可使用 `更新網站資料.ps1`，macOS 可使用 `更新網站資料.command`。

GitHub Actions 的 `Prepare Google Sheet data update` 可以從試算表準備資料更新並建立待審查 Pull Request，不會直接覆寫 `main`。請先檢查資料差異再合併。

網站可部署至 GitHub Pages 或其他靜態網站服務。更完整的資料格式與維護說明請參閱 [ARCHITECTURE.md](ARCHITECTURE.md) 及倉庫內文件。
